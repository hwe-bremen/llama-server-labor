# Passwortrücksetzung ihrer Kundenaccounts

Sehr geehrte Kundinnen und Kunden,

#### Aufgrund einer technischen Notwendigkeit wurden, im Zuge der Umstellung auf unseren neuen Shop, die **Passwörter der bestehenden Kundenaccounts zurückgesetzt**.

Sofern Sie einen Kundenaccount bei uns haben, hat **das Shopsystem Ihnen eine E-Mail diesbezüglich geschickt**.  
Diese Mail wurde automatisiert an die Ihrem Account zugehörige E-Mail-Adresse versandt.

Bitte entschuldigen Sie die Unannehmlichkeit. **Nachdem Sie sich ein neues Passwort zugewiesen haben, können Sie sich wieder in ihren Account einloggen**.

Sollten Sie die betreffende E-Mail bereits gelöscht haben, können Sie hier ihr Passwort aktiv zurücksetzen:

[Passwort zurücksetzen](https://www.henneverpackung.de/de/password_reset)
