# Anforderung: vorgabe_nachtrag

Verbindliche Vorgabe von Hawe, woertlich. Spec, Umsetzung und Review werden an diesem Text gemessen;
die Spec ist ein Loesungsvorschlag und kann falsch sein. Nur Hawe aendert diese Datei.

## Aufgabe

> Nachträge aus der Gegenprüfung K11a: Tests können in der Spec als (Bestand) gekennzeichnet werden – sie prüfen bewusst Bestehendes, müssen vorab grün sein und zählen in der Gegenprobe nicht als Abweichung. Eine Nacharbeit startet nicht, solange die Vorgabe-Tests offene Änderungen haben. Die wirkungslose Ausnahme in Prüfung (b) entfällt. Der Umsetzer schreibt nur Code.
