# Anforderung: vorgabe_tests

Verbindliche Vorgabe von Hawe, woertlich. Spec, Umsetzung und Review werden an diesem Text gemessen;
die Spec ist ein Loesungsvorschlag und kann falsch sein. Nur Hawe aendert diese Datei.

## Aufgabe

> Rollenteilung Tests vorab absichern: Eine Spec mit Abschnitt ## Vorgabe-Tests erklärt tests/test_<kt>.py zur Vorgabe. Neuer Befehl tests-pruefen prüft vor dem Start: je Test-ID eine Methode, Skript lädt, jeder Test rot ohne Umsetzung. umsetzung-auto startet den Erstlauf nur bei bestandener Prüfung, nennt die Vorgabe im Prompt und meldet jede Änderung an der Testdatei als Verstoß. Der Umsetzer schreibt nur Code.
