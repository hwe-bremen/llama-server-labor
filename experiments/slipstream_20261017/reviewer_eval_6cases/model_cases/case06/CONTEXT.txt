Python 3.11+, ein Prozess und Eventloop; acht feste registrierte Mandanten. Ungültige Mandanten-IDs werden vorher in der API abgewiesen. Repository.search liefert einen mandantenprivaten Snapshot und darf warten. Nach Datenänderungen folgt invalidate(tenant). Bereits laufende Aufrufe dürfen ihren begonnenen Snapshot zurückgeben; veraltete Resultate dürfen danach nicht neu im Cache verbleiben. Doppeltes gleichzeitiges Nachladen ist erlaubt. Der Cache ist eine beschleunigende LRU-Ablage, kein persistenter Datenspeicher.
