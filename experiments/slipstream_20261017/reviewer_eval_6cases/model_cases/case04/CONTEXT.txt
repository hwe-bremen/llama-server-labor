Python 3.11+, ein Prozess und Eventloop. Mehrere unabhängige Sessions rufen chat gleichzeitig auf. Die lokale SQLite-Datei wird ausschließlich durch diese Klasse genutzt. Model.generate kann einige Sekunden warten. User- und Assistant-Turn sollen pro erfolgreichem Aufruf gemeinsam gespeichert werden; bei Fehler oder Abbruch darf kein halbes Paar bleiben. Die API verwendet unterschiedliche Sessions, dieselbe Datenbank und dieselbe ChatJournal-Instanz.
